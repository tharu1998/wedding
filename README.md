# Digital Wedding Invitation (Dewmi & Daham)

A modern, responsive, interactive digital wedding invitation with video hero background, countdown timer, strict form validations, and built-in Admin RSVP dashboard.

## Features:
1. **Video Hero Section**: Smooth intro video background.
2. **Interactive Cards**: High-resolution image view and event location details.
3. **Real-time Countdown Timer**: Dynamically updates days, hours, minutes, and seconds.
4. **Strict Form Validation**: Validates full name, Sri Lankan phone numbers, and email formats.
5. **Admin Portal**: Secret dashboard (`admin123`) to track RSVPs, guest counts, and status without external backend dependencies.

## Structure:
- `index.html` - Main HTML Structure
- `style.css` - Styling & Responsive Layout
- `script.js` - Dynamic logic & RSVP system
- `assets/` - Media files (video & photo)
